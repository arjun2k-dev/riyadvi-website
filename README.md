# Riyadvi Software Technologies — Corporate Website Revamp

## Locked Technical Stack
- **Frontend:** React.js (Vite) + TailwindCSS + React Router v6
- **3D & Animation (6 Libraries Implemented):**
  1. `three` (Three.js — custom geometries, materials, vector math)
  2. `@react-three/fiber` (Declarative Three.js inside React & `useFrame` loops)
  3. `@react-three/drei` (`Float`, `Html`, `MeshDistortMaterial`, `OrbitControls`, `Sparkles`, `Stars`, `Line`)
  4. `gsap` (GSAP timelines & ScrollTrigger synchronization)
  5. `lenis` (Smooth inertial scrolling synced with GSAP ScrollTrigger)
  6. `framer-motion` (3D magnetic tilt cards & UI micro-interactions)
- **Backend:** Node.js + Express.js
- **Database:** MongoDB (Mongoose)
